# Kriyank Patil — Data Analytics Portfolio

A personal, responsive portfolio with an editorial layout, Kriyank’s LinkedIn profile portrait, custom SVG illustrations, and restrained motion. It presents his analytics focus, selected projects, internships, education, and Credly credentials.

## Open the portfolio

Open index.html in a modern browser. The site uses plain HTML, CSS, and JavaScript with no build step or JavaScript dependencies. Google Fonts are used when available; local system fonts are the fallback.

## Design

The visual direction pairs bold editorial typography and image-led project storytelling with a simple recruiter path through the profile. Custom illustrations describe project scope and process; they are explanatory visuals, not screenshots or project results. The decorative hero art describes an analysis workflow and does not represent a dataset.

The motion includes subtle line drawing, a repeating text ribbon, project-art hover states, and scroll reveals. Reduced-motion preferences are respected.

## Included sections

- Profile introduction and contact links
- About and analysis approach
- Vehicle Vault and Rule-Based Expert Chatbot project summaries linked to GitHub
- Analytics toolkit
- Internships and a separate education section with the Information Technology diploma and B.E., analytics specialization, SAP Data Analyst training, and Code Unnati foundation course
- Six Credly badges and verified credential details

Project descriptions reflect the public repository material and supplied certificates. No performance metrics or work results have been invented.
